# BEYOND 1.3.0

## New features
- Hands-free voice conversations with an orange call circle, reactive audio waveform, Pause/Resume, confirmed spoken hang-up, optional transcript export, and supported-browser screen wake lock.
- Working notes for active conversation context and optional answer checking against calculations, document excerpts or public search.
- Python syntax checking on generated code blocks, without executing the code.
- Think it through mode and a compact + menu for chat tools.
- Host /status and /model commands, direct current-model answers, and confirmed clearing of local error history.
- Better missing-input questions and natural-language access to existing read-only tools.

## Limits in this first version
Voice transcription and AI replies can be imperfect. Use End if a spoken hang-up is misheard. Battery/browser policies may override screen wake requests; changing apps or locking the phone pauses the session. CPU-only replies may take longer. Voice turns retain normal chat/audio storage even when transcript export is off.

Think it through and answer checking do not guarantee correctness. Syntax checks do not execute code or verify program logic. Further quality improvements are deferred. Multi-part /steps drafting is not included.

## Updating
Use Settings → Updates, or the included Update-Beyond.cmd launcher. Chats, memories, settings, models and user files are preserved. Close active work before updating. Python 3.14 (64-bit) remains required.
