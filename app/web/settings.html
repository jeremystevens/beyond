Settings

You're on another device, so you can look but not change anything. Settings can only be changed on the PC BEYOND runs on.
Restart BEYOND for the new port or network setting to take effect.

AI server

The AI BEYOND talks to, for example Local AI Studio's engine, LM Studio or Ollama. BEYOND's own built-in engine arrives later; until then, enter the address of one you already run.

Only needed for servers that host several models at once, such as Ollama.

House rules

Instructions BEYOND follows in every chat, for example "Always answer in under 3 sentences" or "Use metric units". You can also type /rule <text> and /rules in a chat. They're saved straight away (no need to press Save).

    BEYOND's address

    The number at the end of BEYOND's address (http://127.0.0.1:). Change it only if another program needs this one.
