AI engine and models

AI engine

Where BEYOND's answers come from: its own built-in engine (llama.cpp, started and stopped by BEYOND, on the processor), or an AI server you already run.

Built-in engine

Open Models to load, unload or switch models and save settings for each one.

BEYOND starts llama.cpp's llama-server.exe (a CPU build) with your .gguf model on a free port only this PC can reach, checks that it's healthy, restarts it if it stops, and closes it when BEYOND quits. Saving new settings here restarts it with them.

The engine's own messages are in data\engine.log.

AI server

An OpenAI-compatible AI server you already run, for example Local AI Studio's engine, LM Studio or Ollama.

Only needed for servers that host several models at once, such as Ollama.

Chat and everyday use

Persona

Choose how BEYOND speaks in chat. Your choice applies to the next AI reply, across chats and devices. It stays saved without restarting the app or reloading your model.

House rules

Instructions BEYOND follows in every chat, for example "Always answer in under 3 sentences" or "Use metric units". You can also type /rule <text> and /rules in a chat. They're saved straight away (no need to press Save).

    Chat prompt

    The optimized default keeps BEYOND's instructions short for faster first replies. You can use your own instructions instead. House rules, memories and honest tool use still apply.

    Improve & optimize uses your loaded AI to edit the text above, or the optimized default when the editor is empty. Review the draft, then Save prompt to apply it.

    Spoken replies (/speak)
    
      
    Read the last answer with /speak, use /speak followed by your own text, or press Read aloud
        under an answer. Audio is made on this PC and saved in the chat with Play controls. Kokoro is preferred;
        Piper is the fallback. Voice model files must already be on this PC.
    
      
      
      
      
      
      
      
      
      
      
      
      
      
    
        
        
        
      
    
      
    Press Save. Settings affect newly generated audio; saved clips keep their original voice.
        Long answers read their first 1800 characters. Explicit /speak text is limited to 1800 characters.

    Popups and the tray
    
      
    BEYOND lives in the Windows tray (the icon by the clock: Open BEYOND, Pause popups, Quit) and keeps
        running when the browser is closed. Windows popups only come while you're not looking at BEYOND's page;
        clicking one opens that chat. Press Save after changing these.

    Photos and pictures
    

    
    
      
    Photo understanding (/look)
    
      
    Runs a separate CPU vision process for each photo, usually about 1–2 minutes.
        Chat stays available. Use Gemma 3 with its matching projector and a CPU llama-mtmd-cli.exe.
        Your file paths stay in this PC's settings; fresh downloads have none configured.
    
      
      
      
      
      
      
      
      
    
        
        
      
    
      
    Press Save. Changes apply to the next photo. Finished-photo popups use "When the AI has replied" under Popups and startup.
    
    
    

    
    
      
    Picture generation (/imagine)
    
      
    DreamShaper runs locally in a separate CPU process. Choose Quick (~1–2 minutes),
        Good (~3–5 minutes), or Best (~9–12 minutes) in chat. Times vary; chat stays available.
        Use sd-cli.exe from the CPU folder, not a GPU build. The optional Improve prompt button uses your
        existing chat AI; common image defects are avoided automatically.
    
      
      
      
      
      
      
    
        
        
      
    
      
    Press Save. Changes apply to the next picture. Finished-picture popups use
        "When the AI has replied" and include a preview where Windows supports it.

    Sign-in
    
      
    Other devices (your phone, a work laptop) sign in before they can use BEYOND; this PC never
        needs to. There are two passwords: the sign-in password for using BEYOND, and the administrator
        password, which also lets a device do what only this PC can: change settings, download models and manage
        sign-in.
    
      
    
        
        
    
          
    Sign-in password
