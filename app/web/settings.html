Settings

You're on another device, so you can look but not change anything. Settings can only be changed on the PC BEYOND runs on.
Restart BEYOND for the new port or network setting to take effect.

AI server

The AI BEYOND talks to, for example Local AI Studio's engine, LM Studio or Ollama. BEYOND's own built-in engine arrives later; until then, enter the address of one you already run.

Only needed for servers that host several models at once, such as Ollama.

Photo understanding (/look)

Runs a separate CPU vision process for each photo, usually about 1–2 minutes. Chat stays available. Use Gemma 3 with its matching projector and a CPU llama-mtmd-cli.exe. Your file paths stay in this PC's settings; fresh downloads have none configured.

Press Save. Changes apply to the next photo. Finished-photo popups use "When the AI has replied" below.

Picture generation (/imagine)

DreamShaper runs locally in a separate CPU process. Choose Quick (~1–2 minutes), Good (~3–5 minutes), or Best (~9–12 minutes) in chat. Times vary; chat stays available. Use sd-cli.exe from the CPU folder, not a GPU build. The optional Improve prompt button uses your existing chat AI; common image defects are avoided automatically.

Press Save. Changes apply to the next picture. Finished-picture popups use "When the AI has replied" and include a preview where Windows supports it.

House rules

Instructions BEYOND follows in every chat, for example "Always answer in under 3 sentences" or "Use metric units". You can also type /rule <text> and /rules in a chat. They're saved straight away (no need to press Save).

    Memory

    Saved facts (/remember, /memories) are always used. These two are extras; press Save after changing them.

    Looking things up

    Popups and the tray

    BEYOND lives in the Windows tray (the icon by the clock: Open BEYOND, Pause popups, Quit) and keeps running when the browser is closed. Windows popups only come while you're not looking at BEYOND's page; clicking one opens that chat. Press Save after changing these.

    Leave both empty for no quiet hours.

    BEYOND's address

    The number at the end of BEYOND's address (http://127.0.0.1:). Change it only if another program needs this one.
